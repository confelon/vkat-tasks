Not generated yet — run: docker compose run --rm weather python -m app.experiments weight

Why weight 0.2 was chosen: on accuracy the three options tie fleet-wide (middle chart — zoomed 5×, the whole swing is ~0.01 °C), so the tie-breakers decide — 0.2 keeps the mean bias closest to zero (right chart) and wins the per-city vote (left chart). The effect is geographic: recency weighting compensates fast-warming continental climates (Tashkent, Bishkek, Almaty) and costs a little in some European ones; no city's response exceeds the ±0.1 °C noise floor, which is why the anomaly list below is typically empty.
